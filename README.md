# Receita de Massa Carbonara
Projeto desenvolvido durante a Semana 02.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Funcionalidades
- Página de receita de massa carbonara
- Layout responsivo
- Cabeçalho utilizando Flexbox
- Card para os ingredientes
- Checklist de ingredientes: clique em um ingrediente para marcar ou desmarcar como feito
- Formulário para comentário

## Como executar
Abra o arquivo `index.html` em um navegador.

## Estrutura do projeto
- `index.html` — estrutura da página
- `style.css` — estilos e responsividade
- `script.js` — interação com os ingredientes
- `README.md` — documentação do projeto

## Dificuldades encontradas
- Adaptar o layout para diferentes tamanhos de tela usando CSS responsivo.
- Implementar a interação em JavaScript para marcar e desmarcar os ingredientes.

## Como resolvemos
- Utilizamos CSS responsivo e uma media query para adaptar o layout a diferentes tamanhos de tela.
- Utilizamos JavaScript com eventos de clique e `classList.toggle()` para criar a interação de marcar e desmarcar os ingredientes.
